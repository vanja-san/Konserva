## ✨ Возможности

| | |
|---|---|
| ⚡ **Создание в один клик** | Выберите версию и загрузчик — сервер готов за минуту |
| 🎮 **Все загрузчики** | Vanilla · Fabric · Forge · NeoForge · Paper · Quilt · Purpur |
| 🖥️ **Консоль в реальном времени** | Вывод логов, отправка команд, перезапуск одной кнопкой |
| 🧩 **Моды и плагины** | Просмотр установленного, подробная информация, удаление |
| ☕ **Менеджер Java** | Авто-поиск Java · Авто-подбор версии · Ручной выбор |
| 💾 **Настройка RAM** | Индивидуальный лимит памяти для каждого сервера |
| 🔄 **Авто-перезапуск** | Автоматический перезапуск после вылета |
| 🛠️ **Редактор свойств** | GUI для `server.properties` — без ручного редактирования |
| 📦 **Портативность** | Все данные рядом с программой — без установки и реестра |
| 🌐 **Два языка** | Английский и русский интерфейс с переключением на лету |

## 🚀 Быстрый старт

1. **Скачайте** последнюю версию из [Releases](../../releases)
2. **Распакуйте** архив и запустите `Konserva.exe`
3. **Нажмите +** для создания первого сервера

> Сервер запустится на порту `25565` по умолчанию.

## ❓ Частые проблемы

| Проблема | Решение |
|---|---|
| **Сервер не запускается** | Проверьте логи в консоли. Убедитесь, что Java установлена и совместима (Java 25+ для 26.1.x, Java 21 для 1.20.5+, Java 17 для 1.18–1.20.4). Убедитесь, что порт `25565` свободен. |
| **Ошибка EULA** | Откройте `.\Servers\<имя>\eula.txt`, измените `eula=false` → `eula=true`, перезапустите сервер. |
| **Не хватает памяти** | Увеличьте **Макс. RAM** в настройках сервера. Закройте другие тяжёлые приложения. |

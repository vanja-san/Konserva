# Konserva

Менеджер серверов Minecraft для Windows

Создавайте, запускайте и управляйте локальными серверами Minecraft через удобный графический интерфейс. Никакой командной строки и ручного редактирования конфигов.

> Название образовано от **con**sole + **serv**er — всё «законсервировано» и готово к использованию.

[**Скачать**](../../releases) · [Инструкция по сборке](BUILD.md)

## Возможности

- Создание сервера в один клик — Vanilla, Fabric, Forge, NeoForge, Paper, Purpur
- Авто-установка любой версии Minecraft
- Запуск / Остановка / Перезапуск с консолью в реальном времени
- Графический редактор `server.properties`
- Настройка памяти (мин./макс. RAM) для каждого сервера
- Авто-перезапуск после падения
- Просмотр модов и плагинов с возможностью удаления
- **Менеджер Java**
  - Авто-поиск установленных версий Java
  - Ручное добавление Java через настройки приложения
  - Авто-подбор совместимой версии для каждого сервера
  - Снимите авто-выбор, чтобы указать версию вручную
- Несколько серверов — разные версии работают одновременно

## Быстрый старт

1. **Скачайте** из [Releases](../../releases)
2. **Распакуйте** архив и запустите `Konserva.exe`
3. **Нажмите +** для создания первого сервера

Сервер запустится на порту `25565` по умолчанию.

## Системные требования

- **ОС:** Windows 10 (1903+) / Windows 11
- **ОЗУ:** 2 ГБ (для программы) + ОЗУ для сервера
- **Диск:** 200 МБ (для программы)

Рекомендации по ОЗУ для сервера: [Server Requirements](https://minecraft.wiki/w/Server/Requirements) и [Dedicated Servers](https://minecraft.wiki/w/Server/Requirements/Dedicated).

## Частые проблемы

**Сервер не запускается**
- Проверьте логи в консоли
- Убедитесь, что Java установлена и совместима (Java 25+ для 26.1.x, Java 21 для 1.20.5+, Java 17 для 1.18–1.20.4)
- Убедитесь, что порт `25565` свободен

**Ошибка "EULA not accepted"**
- Откройте `.\Servers\<имя>\eula.txt`
- Измените `eula=false` → `eula=true`
- Перезапустите сервер

**Не хватает памяти**
- Увеличьте **Макс. RAM** в настройках сервера
- Закройте другие тяжёлые приложения

## Хранение данных

Все данные (конфиги, серверы, логи, переводы) хранятся в той же папке, что и исполняемый файл.
